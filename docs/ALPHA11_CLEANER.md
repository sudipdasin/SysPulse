# Alpha.11 Cleaner
Native Storage & cleanup > Cleaner; Overview shortcut. Four modes: quick account cache (25k entries/10s), deep account home (150k/45s), advanced selected directory (300k/60s), custom selected directory with minimum listed size and cache age >=7d. Deadline cooperative, a filesystem syscall can block; scan worker not GUI thread, cancel between entries. Descriptor-relative no-follow traversal, skip other devices, depth 64, largest/candidates/possible leftovers each capped at 250, partial results explicitly marked. No file contents read. Whole-volume statvfs used/available/reserved chart, logical-size category chart, top-five largest-file chart; hardlinks/sparse files and unscanned space make logical totals distinct from actual allocated/reclaimable bytes. Symlink scan roots refused. User sees names, locations, copy exact path/open containing folder, possible .tmp/.log/.bak/.old/partial names are not proven orphan files. Exact dpkg ownership lookup does not imply safety if no owner found. Installed package inventory by dpkg reported installed size, name filter; APT simulated autoremove, reviewed download cache/journal cleanup and native package manager links; no arbitrary automatic uninstall. No privileged file deletion.

Cache removal only explicitly selected (max 100), account passwd-derived ~/.cache, regular user-owned single-link entries with old mtime and ctime >= chosen days, fixed no-follow cache root and descendant directory descriptors, same device and unchanged identity/size/timestamps before unlink. Permanent explicit confirmation default No; unrepresentable/control-character paths excluded from selection, no directory deletion. Close applications before deletion. Concurrent same-user rename between final stat and unlink is a residual race; no claim of atomic identity-bound unlink. Cache contents can still matter to users; no automatic deletion or blanket orphan classification. Re-scan to observe actual free space. Non-root fixture exercises real unlink with injected future clock; no actual user's files touched by tests.
