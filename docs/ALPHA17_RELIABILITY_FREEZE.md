# Reliability freeze — Cleaner root handling

User-reported Quick scan failure: the UI displayed the home folder but scanned passwd ~/.cache; all symlink components were rejected, and missing cache was indistinguishable from access failure. This batch uses the actual XDG cache location and GUI home directory, displays the selected scope, resolves an explicitly requested scan root read-only, distinguishes missing cache from dangling links or errors, and preserves no-follow traversal and deletion checks. Nonstandard or redirected cache scopes cannot be deleted by SysPulse. Failed scans do not display measured-zero totals. Deletion invalidates stale charts and file tables. No new catalog actions. Regression tests exercise Quick mode, alternate cache, missing cache, dangling links, normal custom scope and redirected directory without relaxing deletion safeguards. Physical Mint verification pending. Other user-reported features require individual reproductions; passing fixture tests is not proof of target functionality.
