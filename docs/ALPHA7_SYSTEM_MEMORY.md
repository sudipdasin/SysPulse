# Alpha.7 system-wide memory optimizer

The primary memory optimizer now locates reviewed kernel zswap activation and disable-new-admissions operations, rather than presenting process-local allocator trim as system-wide optimization. Existing process review, startup review and memory history remain. The fixed helper is installed as an ordinary binary, not setuid; the existing reviewed catalog requires pkexec with administrator authorization. The helper only accepts enable/disable, checks effective root, writes a single fixed sysfs parameter after confirming sysfs filesystem type, and verifies the resulting kernel state. Enabling requires disabled zswap, verified active ordinary swap, and no detected zram devices. Conservative policy refuses incomplete readings or zram presence. No swapoff, cache flush, package installation, automatic process termination, persistent configuration or arbitrary shell command. Enabling affects future swap writes and may reduce disk I/O, not promise immediate free memory. Disabling does not empty existing compressed entries. System-wide state can be changed by other tools; refresh and verify before interpreting results. These are runtime settings, not a persistent boot configuration.
