# Settings & help update UI candidate

Adds a manual asynchronous cached APT package version check, official SysPulse release link and installed Mint Update Manager launcher in the existing Settings & help page. No startup network request, privileged command, repository enrollment or unsigned package installation. Local APT metadata is not proof of current signed release. No configured production signed feed. Native Qt build and interaction tests are pending. This is a source candidate, not a completed automatic updater or DEB.
