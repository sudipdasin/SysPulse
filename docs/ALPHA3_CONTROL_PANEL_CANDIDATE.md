# Alpha.3 Control Panel, memory relief and application update candidate

Owner reported the old alpha.2 package lacks the requested functionality. This candidate retains the approved Qt shell, adds one Control Panel navigation destination with eight categories and 37 optional native settings launcher entries (63 total including the existing 26), built-in workspace shortcuts, a memory optimizer page and explicit update controls in Settings & help. Existing 12 destinations and six performance tabs remain. Availability is based on trusted system executables; external utilities are not embedded engines, do not cover every possible Linux configuration, and must be installed separately. Existing native authentication and explicit review are preserved. No changes performed at startup.

Memory relief reads global RAM/swap and Linux memory-pressure measurements; the one-click actual operation invokes glibc malloc_trim for SysPulse only and measures its approximate RSS before/after. It does not drop kernel caches, kill apps, tune swap or guarantee faster system performance. Larger system-wide savings require reviewed process/startup actions or supported compressed-swap configuration. The independent C++ memory relief core passed 11 local tests with strict warnings and UBSan as an unprivileged user, exact two source hashes checked. Native Qt wiring, layout and new regression assertions are NOT compiled or run. Update page reads local APT cached versions asynchronously, offers Mint Update Manager and official releases. No automatic update check/install or live signed production feed yet. No official signed DEB produced. This source-only candidate is versioned alpha.3 to distinguish it from the installed old binary. The earlier pinned alpha.2 build script remains historical and must not be treated as alpha.3 installer. No GitHub Actions or CircleCI. Full Qt/target VM and actual package upgrade gate mandatory before promotion or release.
