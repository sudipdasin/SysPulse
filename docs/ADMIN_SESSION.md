# Session-only administrator authorization
Settings & help → Administrator session → Remember administrator authorization for this SysPulse session → Unlock. The desktop PolicyKit dialog authenticates the normal admin account; no app password input. A root broker is reached only through an inherited Unix socketpair, has no listening endpoint, fixed seven-action allowlist, clean command environment, bounded output and execution, and exits at EOF. No user-supplied command/arguments, stored password, sudoers modification or global authentication cache. Each maintenance action still requires its existing confirmation. Lock now or close the app revokes the session. A denied or interrupted response is not automatically retried. Active operation must finish before normal close; after crash an already authorized operation may finish before broker exits. Separate native utilities, service management, updater and root volume scan still prompt independently; do not claim universal session coverage. Actual Mint PolicyKit authentication and repeated actions require target testing.

Runtime gate: two actual APT cache cleanups via one installed broker in disposable root container, EOF shutdown, unknown/argument-injected/oversized request rejection, non-root broker refusal, normal GUI locked default. This does not exercise the physical PolicyKit dialog. No user data is used.
