# Alpha.23 startup and volume Cleaner

- Startup: parent missing-dependency buttons before making them visible. Count all Qt top-level show events during construction and startup; require exactly one main window. Run under virtual X11 as well as offscreen.
- Whole disk / mounted filesystem: select root or a mounted local data filesystem, refresh list on demand, 3 min/1m or 10 min/3m entry budgets. Custom still accepts a folder; quick/deep unchanged. Filesystem capacity includes space not visible to the scan. Permission failures and intentional mount/alias exclusions counted separately. No traversal across device or statx mount boundary; no directory symlink following. Extended budget can still produce partial results. No raw block-device or unmounted filesystem scanning.
- Administrator mode: explicit confirmation, PolicyKit, fixed trusted read-only helper, exact canonical mounted local filesystem only. The helper reads metadata, not file contents, with bounded output and deadline. It never deletes files or creates deletion candidates. Private names can be displayed locally; never included in diagnostic sharing. Normal-user scan supports cancellation and duplicate comparison; admin scan has a bounded deadline, no claimed cancellation while privileged. The GUI must never be launched with sudo.
- Cleanup: old individually reviewed eligible files in standard user cache only, revalidation before unlink, existing APT download cache and archived journal cleanup through approved system actions. Redirected/nonstandard cache remains inspection-only; arbitrary system files, personal files and duplicates are not automatically deleted.
- Production updater remains dependent on owner-enrolled signed feed; no release signing key or private audit material included. Tests distinguish virtual X11 and root container from real Mint hardware/PolicyKit interaction.
