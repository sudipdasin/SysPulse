# Alpha.15 graphical menu correction

The XFCE Desktop settings page had an independent button loop. Alpha.15 routes all eight through the shared rich launcher tile, with distinct 40 px vector icons, descriptions, availability and hover help. Existing command arguments and permission decisions remain unchanged. The other 63 native launchers share the same card. In-app labeled buttons, tab chips and menu actions gain icon and hover metadata, with show-time decoration of dialogs and standalone entry points. Safety labels, tables and controls remain textual where needed. Icons are cached, no animation timer or network asset. External XFCE applications retain their own appearance. Tests check eight distinct desktop icons, 63 other launchers, tooltips, button coverage and a late-created dialog. No new maintenance capability claimed.
