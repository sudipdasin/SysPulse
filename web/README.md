# Website preview
Static single-file project website, not a live remote administration interface. Shared Precision refinement palette. No external fonts, scripts, telemetry or embedded machine information. Local Chromium via Playwright set_content tested 360, 768, 1440 CSS-pixel widths: no horizontal overflow, six feature cards, keyboard skip link, no external requests and no page errors. Internal fragment targets verified by HTML parsing. Local file navigation is blocked by the test environment; rendering was performed with set_content. External links were not navigated. No full accessibility audit or hosted deployment. The illustration is not an application screenshot. No CI workflows.
