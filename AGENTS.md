# SysPulse development instructions

This repository is the canonical community project. Read docs/PROJECT_HANDOFF.md and docs/source-intake/REPORT.md plus manifest and queue at the beginning of every development cycle. Consume accepted utility IDs, avoid duplication, implement in small isolated branches, test locally, update the queue and report with exact evidence, and merge only validated changes. Never trigger GitHub Actions or CircleCI, even indirectly; verify triggers before ref writes. No paid services or stable release without owner approval. Protect existing features. Prefer native C++/Qt with bounded resources, argument-array subprocesses, least privilege, preview and reversible changes. Never execute incoming raw scripts; inspect privately, sanitize and review all outgoing material before any remote write. No original personal source, logs, configs, real paths, serials, credentials, private metadata or unreviewed binary archives. Never weaken safeguards to finish a task. Report actual blockers, not invented success. No automatic telemetry. Keep future Pro separate; obey GPL and third-party terms.
